  ⚠  GPIO 34, 35, 36, 39 are INPUT-ONLY on the ESP32.
     They have NO internal pull-up resistor.
     Wire a 10kΩ resistor from each of these pins to 3.3V.

                         ESP32 DevKit v1  (38-pin)
                    ┌─────────────────────────────┐
                    │  EN              GPIO23/MOSI ├─ LCD MOSI   (EXP2-6)
                    │  GPIO36/END_L*   GPIO22      │
                    │  GPIO39/END_R*   GPIO1 (TX)  │
                    │  GPIO34/ENC_CLK* GPIO3 (RX)  │
                    │  GPIO35/ENC_DT*  GPIO21      │
                    │  GPIO32/ENC_SW   GPIO19      │
                    │  GPIO33/LCD_RST  GPIO18/SCK  ├─ LCD SCK   (EXP2-2)

================================================================================
  WIFI BEHAVIOUR
================================================================================

  Boot sequence:
    1. Load saved WiFi credentials from flash (Preferences/NVS)
    2. If credentials exist → connect to home network (10 second timeout)
    3. If connected → Station mode, web UI at http://<assigned IP>
    4. If not connected → Access Point mode
         SSID:     CameraSlider
         Password: slider123
         IP:       192.168.4.1
         Opens captive portal at http://192.168.4.1/setup

  Captive portal:
    Connect phone/PC to "CameraSlider" WiFi, browser opens automatically.
    Enter home WiFi SSID and password, device saves and restarts.

  Reset WiFi credentials:
    Physical menu → WiFi Status → Reset WiFi Creds → Yes
    Or via API: POST /api/wifi with new credentials

  Web UI:   http://<ip>/
  REST API: http://<ip>/api/...

================================================================================
  REST API ENDPOINTS
================================================================================

  GET  /api/status       Position, state, program, loop, WiFi info
  POST /api/home         Trigger homing sequence
  POST /api/start        Start selected program
  POST /api/stop         Stop running program
  POST /api/pause        Pause running program
  POST /api/resume       Resume paused program
  POST /api/estop        Emergency stop
  POST /api/jog          Body: {"dir":"left"|"right","fast":0|1}
  POST /api/jog/stop     Stop jog motion
  POST /api/select       Body: {"slot":0-5}  (4=FullLoop, 5=ToEndpoint)
  POST /api/fullloop     Body: {"speed":mm/s,"loops":count}
  POST /api/wifi         Body: {"ssid":"...","pass":"..."} — saves and restarts
