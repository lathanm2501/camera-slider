================================================================================
  ENDSTOP WIRING  (both switches in parallel)
================================================================================

  Left endstop  (NC) ──┐
                        ├── D12 ── Arduino
  Right endstop (NC) ──┘
  Both other legs ─────── GND

  How it works:
    Both switches are Normally Closed (NC). At rest the circuit is closed.
    When either switch is triggered, the circuit opens → D12 reads LOW.
    The firmware knows which end was hit by reading stepper direction:
      stepper.speed() < 0  →  moving left  →  left endstop triggered
      stepper.speed() > 0  →  moving right →  right endstop triggered

================================================================================
  TMC2209 WIRING
================================================================================

  TMC2209 Pin   Arduino / Source    Notes
  ───────────   ──────────────────  ───────────────────────────────────────────
  STEP          D9                  Step pulse
  DIR           D10                 Direction
  EN            GND (direct)        Tied LOW permanently — always enabled
                                    Motor holds position when idle (no free-spin)
  VIO           5V                  Logic supply
  VM            12–24V PSU          Motor power supply
  GND           GND                 Logic and power ground joined at PSU
  A1/M1         Motor coil A+       }
  A2/M2         Motor coil A-       } NEMA 17 wiring
  B1/M3         Motor coil B+       }
  B2/M4         Motor coil B-       }

  MS1/MS2 microstepping pads (on TMC2209 module):
    MS1=GND  MS2=GND  →   8 microsteps
    MS1=VIO  MS2=GND  →  16 microsteps  ← firmware default (STEPS_PER_MM=80)
    MS1=GND  MS2=VIO  →  32 microsteps
    MS1=VIO  MS2=VIO  →  64 microsteps

  IR REMOTE FUNCTION MAP
